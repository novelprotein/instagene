# InstaGene synthetic fixture corpus

This corpus is intentionally small and public. Every biological sequence,
alignment, and recipe here was authored as synthetic test data by InstaGene
contributors; it is not copied from a database, patient record, commercial
tool, or proprietary construct.

The files and their metadata are available under the repository's MIT License.
`manifest.json` is versioned and records each fixture's source statement,
format, license, and SHA-256 digest. Additions or changes must update that
manifest and the hash-verification test in `FixtureManifestTest`.
